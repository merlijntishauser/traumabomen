# Tree list (My trees)

Scope: /trees, the page after unlock. Mode: Operate. Most accounts hold one or two trees, so the old narrow list left the page empty.

Audience and task: someone returning to their family tree, often in a quiet or heavy moment. They want to get back to where they were; occasionally start, rename, import or remove a tree.

User decisions: a welcoming threshold, not a list or a shelf. Decrypt only the most recently tended tree for a rich preview; other trees show plaintext counts.

Must stay: the first-run welcome (no trees), rename/delete row menus with the named irreversible confirm, import, settings, admin link, logout, demo limit.

## Direction contract

THESIS: The page opens on your family, not on a file list. Refuses the category default of a centred project list with a toolbar of create buttons.

OWN-WORLD: Quiet Forest tokens unchanged. A wide band: the latest tree drawn as a read-only silhouette on the canvas surface (miniature nodes with the 3px accent top edge, partner and parent lines in the edge colours, names in the voice face), beside a text column on the page wash.

STORY: The visitor sees their tree as they left it, reads when they were last there, meets one open question, and opens the tree in one click. Other trees and new-tree actions sit quietly below.

FIRST VIEWPORT: Slim header (My trees, import, settings, admin, logout). Band at content width up to 1200px: left two thirds the silhouette (whole preview clickable, opens the tree), right third the tree name in the voice face, meta line, the open question in the voice face, Open tree as primary, Write in your journal as a quiet link. Below: "Other trees" rows when there are any, then Start a new tree and Explore a fictional family. Signature move: the silhouette, the actual canvas layout in miniature.
